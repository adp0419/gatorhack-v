# Gelasio

Locally hosted editorial display font. Source: [Google Fonts / Gelasio](https://github.com/google/fonts/tree/main/ofl/gelasio), downloaded 2026-10-24. The original variable TrueType file is retained without modification as `gelasio-variable.ttf`. License: `OFL-Gelasio.txt` (SIL Open Font License 1.1). No font service is contacted by the application.
