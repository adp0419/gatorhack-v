AccessBench

Audit a website's accessibility

AccessBench opens the site in a real browser, lets Twinly explore it like a visitor, and runs bounded checks in five categories: keyboard operation, forms, text contrast, structure and semantics, and zoom and reflow.

Try the demo site

What an audit covers

  • The start page plus at most two more pages or states that Twinly reaches.
  • Eleven defined checks, each mapped to related WCAG 2.2 criteria. This is not a full WCAG evaluation or certification.
  • Forms are never submitted on public sites; form error behavior is only tested on configured test sites.
  • Reflow is tested at 320 CSS pixels. Text resizing is not tested.
